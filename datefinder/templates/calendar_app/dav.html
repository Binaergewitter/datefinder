🔑 CalDAV-Sync & JSON-API

Erstelle deinen persönlichen Calendar-Key und trage ihn in Thunderbird / DAVx5 / Apple Calendar als Passwort ein, oder nutze ihn für das JSON-API (curl -u Benutzer:KEY).

Kein Key generiert. Erzeuge unten deinen persönlichen Schlüssel.

⚠️ Regenerieren einer Key trennt alle bestehenden Thunderbird-/DAVx5-Synchronisationen ab, bis dort das Passwort (die Key) aktualisiert wird.

📧 Thunderbird einrichten
  1. Kalender-Panel → Neuen Kalender → Im Netzwerk
  2. Typ: CalDAV
  3. Ort: die Server-URL oben ({{ dav_url }})
  4. Benutzername + Calendar-Key als Passwort eintragen
  5. Passwort-Manager verwenden kann deaktiviert bleiben
📱 Mobile Clients (DAVx5 / Apple Kalender)
  1. Server-URL: {{ dav_url }}
  2. Benutzername: {{ user.username }}
  3. Passwort: dein Calendar-Key
🔌 JSON-API (Skripte)

Einträge hinzufügen / ändern / löschen ohne CalDAV-Client, gleiche Daten wie die Reminders-Seite:

Alle Einträge:
curl -u {{ user.username }}:<KEY> {{ api_base }}/api/entries/

Neuer Eintrag:
curl -u {{ user.username }}:<KEY> -X POST -H 'Content-Type: application/json' \
  -d '{"title":"Live-Aufnahme","date":"2026-10-01","description":"Studio"}' \
  {{ api_base }}/api/entries/create/

Eintrag ändern (id aus der Liste):
curl -u {{ user.username }}:<KEY> -X POST -H 'Content-Type: application/json' \
  -d '{"title":"Neuer Titel"}' \
  {{ api_base }}/api/entries/ID/update/

Eintrag löschen:
curl -u {{ user.username }}:<KEY> -X POST \
  {{ api_base }}/api/entries/ID/delete/
